# 龍來刮 網站模板

刮刮卡網路商店的網站模板：前台購物、7-11 取貨付款結帳、LINE 會員登入（限會員下單）、每月消費排名，訂單、會員、商品都由 Google 試算表管理，另有給台主用的「效益試算」小程式。

🔗 **線上預覽：<https://minihorsewang.github.io/longlaigua/>**

> 目前為示範版本，商品、活動都是範例資料。LINE 登入頻道尚在「開發中」狀態，目前只有頻道管理員能登入、下單。

## 功能

| 頁面 | 內容 |
|---|---|
| 首頁 | 主視覺、熱銷商品、各分類商品、熱門活動 |
| 活動 | 活動列表，可依「進行中／即將開始／已結束」篩選，狀態依日期自動判斷 |
| 商品 | 分類選單＋搜尋；畫面左側「產品選單」可快速切換分類；**商品資料由試算表「商品」工作表管理**，支援商品照片 |
| 中獎 | **每月消費排名**（姓名遮罩，前 10 名），可切換月份；首頁公告顯示最新一期第 1 名；活動辦法摺疊在頁面下方 |
| 小程式 | **效益試算**（見下方說明） |
| 會員 | **LINE 登入**，註冊後自動取得會員編號；可綁定蝦皮帳號（參加排名用）；會員中心可查看「我的訂單」與訂單狀態（換裝置也看得到） |
| 購物車／結帳 | 右側滑出購物車 → 確認訂單 → 填寫 7-11 取貨資料 → 完成；**須登入會員才能下單** |

### 結帳流程（7-11 取貨付款，限會員）

1. **確認訂單**：未滿 NT$1,000 運費 NT$80，滿 NT$1,000 免運；未登入時顯示 LINE 登入按鈕，登入（含新會員註冊）後自動回到結帳頁，購物車保留
2. **填寫取貨資料**：收件人姓名（2～10 字）、手機（09 開頭 10 碼）、7-11 門市店號（6 碼）與門市名稱
3. **送出**：訂單寫入 Google 試算表並記下會員編號，顯示訂單編號

| 防護 | 說明 |
|---|---|
| 金額 | 由後端依「商品」工作表重新計算，不採用網頁傳來的金額 |
| 限會員下單 | 後端驗證登入憑證，未登入或憑證無效的訂單一律拒絕 |
| 每日上限 | 同一位會員每天最多 5 筆訂單（`Code.gs` 的 `DAILY_ORDER_LIMIT`） |
| 會員編號 | 由後端依登入憑證查出後寫入訂單，網頁無法指定 |

### 商品管理（Google 試算表「商品」工作表）

網站開啟時讀取「商品」工作表，只顯示勾選「上架」的商品；同一張表也用於訂單金額計算，**改價格只需改試算表**。

| 欄 | 欄位 | 說明 |
|---|---|---|
| A | 商品ID | 必填、不可重複，限英文、數字、`-`、`_`；上架後不要修改 |
| B | 名稱 | 必填 |
| C | 價格 | 必填，大於 0 |
| D | 上架 | 打勾＝顯示；取消＝下架 |
| E | 分類 | 下拉選單：刮刮卡／禮盒組合／周邊小物 |
| F | 角標 | 選填，例如 熱銷、新品 |
| G | 熱銷 | 打勾＝出現在首頁熱銷商品 |
| H | 圖示 | 選填 emoji，沒有照片時顯示；空白用分類圖示 |
| I | 照片網址 | 選填，https 網址；Google 雲端硬碟分享連結會自動轉換；讀不到時自動改顯示圖示 |
| J | 說明 | 選填（網站尚未顯示） |

- 試算表資料會先清理、跳脫再顯示；不完整的列（無商品ID、價格不是正數）自動略過
- 網站會快取上次讀到的商品，開站先顯示快取，約 1～3 秒後換成最新內容
- 商品照片目前建議放在刮刮帳號的 Google 雲端硬碟（資料夾設為「知道連結的任何人可檢視」）；照片建議正方形、約 800×800、1 MB 以內
- 店內另有《龍來刮 商品上架使用說明》PDF（內部文件，不放在此 repo）

### 會員（LINE 登入）

```
客人按「使用 LINE 登入」→ LINE 官方同意頁（附「加入龍來刮好友」選項，預設勾選）
    ↓ LINE 帶著授權碼回到網站
網站把授權碼交給 Apps Script → Apps Script 向 LINE 驗證身分
    ↓
第一次：填姓名、手機、Email 完成註冊 → 寫入「會員」工作表，並自動產生會員編號
之後：直接進會員中心，會員編號、點數等資料從試算表讀取
```

| 項目 | 說明 |
|---|---|
| LINE 頻道 | LINE Developers → RayWang →「龍來刮 會員登入」，與官方帳號「龍來刮 娃娃機 刮刮卡 專賣店」在同一個 Provider，會員 ID 與官方帳號好友 ID 一致 |
| 會員資料 | 試算表「會員」工作表：LINE ID、LINE 名稱、姓名、手機、Email、點數、加入時間、最後登入時間、會員編號、蝦皮帳號 |
| 會員編號 | `LM` ＋ 加入年月（yyMM）＋ `-` ＋ 當月流水號 4 碼，例如 2026 年 10 月第 1 位會員為 `LM2610-0001`，11 月從 `LM2611-0001` 重新算；由後端產生，發出後不會變動，並顯示在會員中心 |
| 登入狀態 | 試算表「登入憑證」工作表只存雜湊值；登入 30 天後需重新登入 |
| 蝦皮帳號 | 註冊時選填，或在會員中心補填**一次**（之後網站上不能自改，需修改請聯絡店家，由店家改試算表）；限英文小寫、數字、`.`、`_`，3～30 字，統一存小寫；一個蝦皮帳號只能綁一位會員 |
| 我的訂單 | 依訂單的「會員編號」從試算表讀取（最近 50 筆），顯示訂單編號、狀態、日期、門市、商品、金額；店家在試算表改「狀態」，客人就會看到 |
| 點數 | 直接修改「會員」工作表的點數欄，客人重新開網站就會看到（目前尚無自動給點規則） |
| 安全 | Channel secret 只存在 Apps Script 的指令碼屬性，不在網站程式碼或 GitHub；登入流程以 state／nonce 防偽造 |

> LINE 登入只能在正式網站使用（必須與 LINE 後台的 Callback URL 一致），本機預覽按登入會提示無法使用。

**為什麼只開 LINE 登入：** Google 登入拿到的是 Google 帳號 ID，和 LINE 官方帳號的好友 ID 對應不起來，無法推播通知給這些會員，因此已移除 Google 登入按鈕。若之後要開放，需另外做「綁定 LINE」功能，並用手機號碼避免同一人重複註冊。

### 每月消費排名（中獎頁）

每月消費金額第 1 名可獲得獎品。**只有網站會員參加**；在蝦皮、7-11 賣貨便下單的客人，也要先加入網站會員（蝦皮客人須綁定蝦皮帳號）才會被計入。

```
店家把出貨檔 Excel 上傳到 Google 雲端硬碟「龍來刮出貨檔」資料夾（覆蓋舊檔或放新檔皆可）
    ↓ 試算表上方選單「龍來刮」→「匯入出貨檔並計算上個月排名」（或指定月份）
程式讀最近修改的 Excel 的「客戶名單」工作表 → 整張覆蓋到試算表「出貨檔」工作表
    ↓
網站訂單＋蝦皮＋賣貨便依規則對應到會員、加總金額、排名
    ↓ 寫入「每月排行」（名次）與「排行明細」（每筆訂單對應結果）
店家確認後在「每月排行」勾選「公布」→ 網站中獎頁與首頁公告顯示
```

| 項目 | 規則 |
|---|---|
| 金額 | 每筆訂單「售價」加總：不含運費、優惠券折抵前；網站訂單用商品小計，狀態含取消／退貨／退款／測試的不計 |
| 月份 | 依下單日分月 |
| 網站訂單 | 依訂單的會員編號（後端驗證登入後寫入） |
| 蝦皮 | 出貨檔買家 ID ＝ 會員綁定的蝦皮帳號（不分大小寫） |
| 賣貨便 | 遮罩手機（前 4 碼＋末 3 碼）＋姓氏對應會員；多位會員符合時標「無法確定」、不計入，由店家人工確認 |
| 略過 | ID 欄是商品文字（例如「龍蛋*10張」）的列、同一訂單編號重複的列；退貨工作表暫不處理 |
| 名次 | 金額相同為同名次；網站只公布已勾選「公布」的月份、每月前 10 名、最近 12 個月，姓名遮罩，不公開金額與會員編號 |
| 匯入 | Excel（.xlsx／.xlsm／.xls）或 Google 試算表皆可；轉檔用的暫存檔用完自動丟到垃圾桶；選單另有「只匯入出貨檔（不計算）」可先檢查資料 |
| 重算 | 同月份可重算（覆蓋該月結果，其他月份不受影響）；已公布的月份鎖定，需先取消勾選才能重算 |

> 出貨檔含客人個資，只放在店家私人的雲端硬碟與試算表，不會上傳到網站或 GitHub。

### 小程式：效益試算

給刮刮卡／娃娃機台主評估一版檯面的獲利，邊輸入邊計算。

- **輸入**：版型（40～240 刮或自訂）、均出（選填）、每刮商品成本、大獎與小獎、完刮獎與清獎賞、月台租、每版目標獲利、每月版數
- **輸出**：建議均出；大獎即停／全獎出完／完刮三種模式比較；禮品配置明細；月營收試算；診斷建議
- **隨機號碼產生器**：輸入總刮數與獎號數量，產生不重複號碼

主要公式：

```
期望停止刮數 = 獎數 ×（總刮數 + 1）÷（獎數 + 1）
建議均出     = ⌈（目標獲利 + 大獎成本 + 期望停止刮數 × 每刮商品成本）÷ 期望停止刮數⌉
整版毛利     = 期望停止刮數 × 均出 − 獎品成本 − 商品成本
月淨利       = 每版毛利 × 每月版數 − 月台租
```

例：80 刮、大獎 A 100 元 × 2、每刮成本 5 元、目標每版獲利 300 → 期望停止刮數 54.0、建議均出 NT$15、每版毛利 NT$340。

> 結果為機率期望值，實際大獎出現位置與營收可能不同，僅供配置參考。

## 修改內容

**商品、價格、上下架**：改 Google 試算表「商品」工作表即可（見上方「商品管理」），不需要改程式。

其他設定在 `app.js` 最上方：

| 要改的東西 | 變數 |
|---|---|
| 訂單／會員／商品服務網址（Google Apps Script） | `ORDER_API_URL`（留空＝示範模式，訂單只存在瀏覽器） |
| LINE 登入頻道 | `LINE_LOGIN`（Channel ID 與 Callback URL，須與 LINE 後台一致） |
| 跑馬燈公告 | `ANNOUNCEMENTS` |
| 活動 | `EVENTS` |
| 商品分類 | `CATEGORIES`（新增分類時，`Code.gs` 的 `PRODUCT_CATEGORIES` 也要一起改） |
| 備用商品（讀不到試算表時才顯示） | `DEFAULT_PRODUCTS` |
| 效益試算預設值 | `PROFIT_DEFAULTS` |
| 運費／免運門檻 | `SHIPPING_FEE`、`FREE_SHIPPING_THRESHOLD`（`Code.gs` 也有同名設定，兩邊要一致） |

後端 `Code.gs` 的設定：每位會員每天訂單上限 `DAILY_ORDER_LIMIT`、7-11 代收金額上下限 `COD_MIN`／`COD_MAX`、排名公布人數 `RANK_PUBLIC_TOP`／月數 `RANK_PUBLIC_MONTHS`、出貨檔欄名 `SHIPMENT_COLUMNS`（Excel 欄名改了要一起改）、雲端硬碟資料夾 `SHIPMENT_FOLDER`、Excel 工作表名稱 `SHIPMENT_SOURCE_SHEET`。匯入出貨檔需要在 Apps Script「服務」加入 Drive API。修改後需在 Apps Script 重新部署「新版本」。

### 如何自行重測

1. 開啟 [線上網站](https://minihorsewang.github.io/longlaigua/)，按 `Ctrl + F5` 更新。
2. 加入一張「幸運刮刮卡（單張）」50 元商品，確認購物車沒有其他商品。
3. 前往結帳（2026-10-14 起須先用 LINE 登入會員），填入測試姓名「網頁測試」、手機 `0900000000`、店號 `000000`、門市名稱「測試門市」。這些是虛構測試資料，不能用於寄件。
4. 備註填「串接測試，虛構資料，勿出貨」，按「送出訂單」。此步驟會新增一筆實際試算表紀錄。
5. 正常結果：網站顯示 LL 開頭訂單編號、總額 130 元；後台「訂單」新增一列，編號與金額相同。
6. 把測試列的 L 欄「狀態」改為「測試勿出貨」，避免誤出貨。

若出錯：

- 顯示 DEMO 編號：先確認 `app.js` 的 `ORDER_API_URL` 已設定、網站部署完成，再重新整理。
- 顯示無法連線：檢查 Apps Script 網頁應用程式是否允許「所有人」、網址是否以 `/exec` 結尾。
- 網站成功但暫時看不到新列：重新整理試算表，依訂單編號查找；確認後再決定是否重送，避免重複訂單。
- 顯示商品或欄位錯誤：檢查「商品」是否上架，以及工作表第 1 列欄位是否與 `Code.gs` 一致。
