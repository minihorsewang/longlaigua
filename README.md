# 龍來刮 網站模板

刮刮卡網路商店的網站模板：前台購物、7-11 取貨付款結帳、訂單寫入 Google 試算表，以及給台主用的「效益試算」小程式。

🔗 **線上預覽：<https://minihorsewang.github.io/longlaigua/>**

> 目前為示範版本，商品、活動、中獎名單都是範例資料。

---

## 功能

| 頁面 | 內容 |
|---|---|
| 首頁 | 主視覺、熱銷商品、各分類商品、熱門活動 |
| 活動 | 活動列表，可依「進行中／即將開始／已結束」篩選，狀態依日期自動判斷 |
| 商品 | 分類選單＋搜尋；畫面左側「產品選單」可快速切換分類 |
| 中獎 | 得獎名單（姓名遮罩），可依活動篩選 |
| 小程式 | **效益試算**（見下方說明） |
| 會員 | LINE／Google 登入（示範模式，尚未串接真正的登入） |
| 購物車／結帳 | 右側滑出購物車 → 確認訂單 → 填寫 7-11 取貨資料 → 完成 |

### 結帳流程（7-11 取貨付款）

1. **確認訂單**：未滿 NT$1,000 運費 NT$80，滿 NT$1,000 免運
2. **填寫取貨資料**：收件人姓名（2～10 字）、手機（09 開頭 10 碼）、7-11 門市店號（6 碼）與門市名稱
3. **送出**：訂單寫入 Google 試算表，顯示訂單編號

訂單金額由試算表端依「商品」工作表重新計算，不採用網頁傳來的金額。

### 小程式：效益試算

給刮刮卡／娃娃機台主評估一版檯面的獲利，邊輸入邊計算。

- **輸入**：版型（40～240 刮或自訂）、均出（選填）、每刮商品成本、大獎與小獎、完刮獎與清獎賞、月台租、每版目標獲利、每月版數
- **輸出**：建議均出；大獎即停／全獎出完／完刮三種模式比較；禮品配置明細；月營收試算；診斷建議
- **隨機號碼產生器**：輸入總刮數與獎號數量，產生不重複號碼

主要公式：

```
期望停止刮數 = 獎數 ×（總刮數 + 1）÷（獎數 + 1）
建議均出     = ⌈（目標獲利 + 大獎成本 + 期望停止刮數 × 每刮商品成本）÷ 期望停止刮數⌉
整版毛利     = 期望停止刮數 × 均出 − 獎品成本 − 商品成本
月淨利       = 每版毛利 × 每月版數 − 月台租
```

例：80 刮、大獎 A 100 元 × 2、每刮成本 5 元、目標每版獲利 300 → 期望停止刮數 54.0、建議均出 NT$15、每版毛利 NT$340。

> 結果為機率期望值，實際大獎出現位置與營收可能不同，僅供配置參考。

## 檔案結構

```
├── index.html            網頁骨架（頁首、產品選單、購物車）
├── style.css             樣式與配色（色票集中在檔案最上方 :root）
├── app.js                所有功能與範例資料
├── tw-11134207-….webp     首頁主視覺與 Logo 的貓貓圖
└── google-apps-script/
    ├── Code.gs           貼到 Google 試算表的接單程式
    └── 說明.md           試算表建立與部署步驟
```

純 HTML／CSS／JavaScript，不需要安裝任何套件。

## 修改內容

都在 `app.js` 最上方：

| 要改的東西 | 變數 |
|---|---|
| 訂單送出網址（Google Apps Script） | `ORDER_API_URL`（留空＝示範模式，訂單只存在瀏覽器） |
| 跑馬燈公告 | `ANNOUNCEMENTS` |
| 活動 | `EVENTS` |
| 商品分類／商品 | `CATEGORIES`、`PRODUCTS` |
| 中獎名單 | `WINNERS` |
| 效益試算預設值 | `PROFIT_DEFAULTS` |
| 運費／免運門檻 | `SHIPPING_FEE`、`FREE_SHIPPING_THRESHOLD` |

> ⚠️ 改商品價格時，Google 試算表「商品」工作表也要一起改：網站顯示 `app.js` 的價格，實際收款依試算表計算。

## 本機預覽

直接用瀏覽器打開 `index.html` 即可；或在資料夾內啟動簡易伺服器：

```bash
python -m http.server 5173
```

再打開 <http://localhost:5173>。

## 上線

推送到 `main` 分支後，GitHub Pages 約 1～2 分鐘自動更新。看到舊畫面時按 `Ctrl + F5` 重新整理。
