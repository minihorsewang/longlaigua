# 訂單寫入 Google 試算表：設定步驟

客人在網站按「送出訂單」→ 訂單自動新增到你的 Google 試算表「訂單」工作表。

## 一、建立試算表並貼上程式（約 5 分鐘）

1. 到 [Google 試算表](https://sheets.google.com) 建立一份**空白試算表**，命名例如「龍來刮訂單」
2. 上方選單「**擴充功能**」→「**Apps Script**」
3. 把編輯器裡原本的內容全部刪掉，貼上 `Code.gs` 的全部內容 → 按 💾 儲存
4. 上方函式選單選 **`setup`** → 按「**執行**」
   - 第一次會跳出授權：選你的 Google 帳號 →「進階」→「前往（不安全）」→「允許」
   - 這是因為程式是你自己寫的、還沒經過 Google 審核，屬正常現象
5. 回到試算表，會看到兩個新工作表：「**訂單**」「**商品**」

## 二、部署成網址

1. Apps Script 右上角「**部署**」→「**新增部署作業**」
2. 左邊齒輪 ⚙️ 選「**網頁應用程式**」
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（客人沒有你的帳號也要能下單）
4. 按「部署」→ 複製「**網頁應用程式網址**」（`https://script.google.com/macros/s/.../exec`）
5. 用瀏覽器打開這個網址，看到 `"ok":true` 就代表成功

## 三、接到網站

打開網站的 `app.js`，最上方：

```js
const ORDER_API_URL = '';
```

把網址貼進引號中間，存檔即可。

## 日常使用

| 要做的事 | 怎麼做 |
|---|---|
| 看新訂單 | 打開試算表「訂單」工作表 |
| 標記出貨 | 改「狀態」欄（例如 待出貨 → 已上傳 → 已出貨） |
| 改價格／下架商品 | 改「商品」工作表的價格，或取消勾選「上架」 |
| 匯出給 7-11 | 篩選「待出貨」→ 複製到 7-11 範例檔；或「檔案」→「下載」→ CSV |

> ⚠️ 改價格時，網站 `app.js` 的 `PRODUCTS` 也要一起改。客人在網站上看到的是 `app.js` 的價格，實際收的是試算表的價格。

## 修改程式後要重新部署

改了 `Code.gs` 之後，要「部署」→「**管理部署作業**」→ ✏️ 編輯 → 版本選「**新版本**」→ 部署。
這樣網址不會變，網站不用改。（如果按「新增部署作業」會產生新網址。）

## 注意事項

- 試算表裡有客人的姓名、手機，**不要分享給別人**
- 「訂單」「商品」工作表名稱和欄位順序不要改，程式靠這些讀寫
- 免費帳號一天可以處理的訂單量對小型網店綽綽有餘
